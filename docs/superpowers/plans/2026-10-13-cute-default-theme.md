# Cute Default Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a pastel "sticker" card the default SVG theme while keeping today's vermilion/gold card available as `theme=classic`.

**Architecture:** `src/render/card.js` becomes a small dispatcher (`resolveTheme` + `renderZodiacCard`) over two renderers in `src/render/themes/`. The current renderer moves verbatim to `classic.js`; the new `cute.js` draws the layout from the spec and gets its characters from `src/render/sticker.js`, which turns per-animal shape data (`src/data/cute-animals.js`) into shadow / white border / outline layers. Fonts are embedded as base64 woff2 subsets generated by `scripts/embed-fonts.js`.

**Tech Stack:** Node ≥18 ESM, plain string-built SVG, `node:test` + `node:assert/strict`, Google Fonts CSS2 API (build-time only), Vercel serverless (`api/card.js`).

**Spec:** `docs/superpowers/specs/2026-10-13-cute-default-theme-design.md`

## Global Constraints

- Default theme is `cute`; `theme=classic` renders the current design with **no visual change**; any other or missing value → `cute`.
- Card geometry unchanged: viewBox `0 0 600 320`, display width default `360`, clamped `240`–`900`.
- Shared colors: ink / outline / body text `#5a3d35`; muted text `#b08890`.
- Fonts: Fredoka (Latin, weights 400 + 600) and ZCOOL KuaiLe (hanzi), both OFL, embedded as base64 woff2 subsets. A card embeds only its own theme's fonts.
- Sticker style: shadow offset `translate(2 3)`, black, opacity `0.12`; white border stroke width `14`; outline `#5a3d35` width `3`; dot eyes with white highlight; blush ellipses.
- Per-animal palettes and pinyin exactly as in the spec tables (copied into Task 2).
- Out of scope: Pinned Gist output, error SVG, README banner, `public/index.html`.
- Every commit message ends with the trailer line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Run tests with `npm test` (the script lists test files explicitly — new test files must be added to it).

## Review Focus

- A long GitHub login / real name / role must not run into the giant hanzi on the right — expect truncation with "…" and the role dropped first (test in Task 5).
- A user with no detected languages must get a clean card with no empty language line or orphan sparkle (test in Task 5).
- A brand-new account with all-zero stats must render without `NaN` and without zero-width bar fills (test in Task 5).
- `width=` must keep working for the cute theme exactly as for classic (test in Task 5).
- Pinyin tone marks (ǔ ǎ ó …) and curly quotes must render in the embedded Fredoka subset when the SVG is loaded as `<img>` — expect no fallback-font glyphs in the tag pill (manual check in Task 3 and Task 6).

```js
export function escapeXml(str) {
  return String(str ?? "")
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&apos;");
}

export function clamp(n, min = 0, max = 100) {
  return Math.max(min, Math.min(max, n));
}

export function wrapText(text, maxChars, maxLines = 3) {
  const words = String(text || "").split(/\s+/).filter(Boolean);
  if (!words.length) return [];
  const lines = [];
  let current = "";
  for (const word of words) {
    const next = current ? `${current} ${word}` : word;
    if (next.length > maxChars && current) {
      lines.push(current);
      current = word;
      if (lines.length >= maxLines) break;
    } else {
      current = next;
    }
  }
  if (current && lines.length < maxLines) lines.push(current);
  return lines;
}

export function secondaryDisplayName(profile) {
  const login = String(profile.username || "").trim();
  const name = String(profile.name || "").trim();
  if (!name || !login) return name && name !== login ? name : "";
  if (name.toLowerCase() === login.toLowerCase()) return "";
  return name;
}
```

```js
import assert from "node:assert/strict";

/** Test helper: every non-self-closing tag must be closed, in order. */
export function assertBalancedTags(svg) {
  const stack = [];
  for (const m of svg.matchAll(/<(\/?)([a-zA-Z][\w:-]*)\b[^>]*?(\/?)>/g)) {
    const [, closing, name, selfClosing] = m;
    if (selfClosing) continue;
    if (closing) assert.equal(stack.pop(), name, `unexpected </${name}>`);
    else stack.push(name);
  }
  assert.deepEqual(stack, [], "unclosed tags");
}
```

```js
  return Object.entries(obj)
    .map(([k, v]) => `${k}="${v}"`)
    .join(" ");
}

function shape({ tag, attrs }, extra = "") {
  return `<${tag} ${toAttrs(attrs)}${extra}/>`;
}

/**
 * Sticker-outline character in a 120×120 box.
 * Layers come from `silhouette` automatically so all 12 animals match:
 * drop shadow → white sticker border → colored shapes with ink outline → `details` on top.
 * @param {{ silhouette: { tag: string, attrs: object, fill: string }[], details: string[] }} def
 */
export function renderSticker(def) {
  const bare = def.silhouette.map((s) => shape(s)).join("");
  const body = def.silhouette.map((s) => shape(s, ` fill="${s.fill}"`)).join("");
  return `<g class="sticker" stroke-linejoin="round">
      <g class="sticker-shadow" transform="translate(2 3)" fill="#000000" stroke="#000000" stroke-width="14" opacity="0.12">${bare}</g>
      <g class="sticker-border" fill="#ffffff" stroke="#ffffff" stroke-width="14">${bare}</g>
      <g class="sticker-body" stroke="${STICKER_INK}" stroke-width="3">${body}</g>
      <g class="sticker-details">${def.details.join("")}</g>
    </g>`;
}
```

```js
/** Cut to maxChars including a trailing "…" when shortened. */
export function truncate(text, maxChars) {
  const s = String(text ?? "").trim();
  if (s.length <= maxChars) return s;
  return `${s.slice(0, Math.max(1, maxChars - 1)).trimEnd()}…`;
}
```

```js
/** Shrink a one-line label to fit (Fredoka ≈ 0.56em per glyph). */
function fitFontSize(text, maxWidth, base, em = 0.56) {
  const len = Math.max(1, String(text).length);
  return Math.min(base, Math.floor(maxWidth / (len * em)));

/** Up to two lines; "…" when the blurb still doesn't fit. */
function descriptionLines(text) {
  const full = String(text || "").trim();
  const lines = wrapText(full, 50, 2);
  if (lines.length && lines.join(" ").length < full.length) {
    const last = lines.length - 1;
    lines[last] = `${lines[last].replace(/[.,;:!?]$/, "")}…`;
  }
  return lines;
}

/** Login + (real name · role); drops role, then real name, before overflowing the column. */
function renderNameLine(profile) {
  const login = truncate(profile.username || profile.name || "developer", 22);
  const parts = [
    truncate(secondaryDisplayName(profile), 16),
    truncate(profile.role || "Software Developer", 20),
  ].filter(Boolean);
  const estimate = () => login.length * 11 + (parts.length ? 8 + parts.join(" · ").length * 7 : 0);
  while (parts.length && estimate() > COLUMN) parts.pop();
  const extras = parts.length
    ? `<tspan dx="8" fill="${MUTED}" font-size="13" font-weight="400">${parts.map(escapeXml).join(" · ")}</tspan>`

      <text x="${LEFT + 18}" y="176" fill="${c.accent}" font-size="14" font-weight="600" font-family="${FONT_ROUND}">${escapeXml(top.join(" · "))}</text>
    </g>`;
}

function renderStats(displayStats, c) {
  const peak = Math.max(0, ...displayStats.map((s) => Number(s.value) || 0));
  return displayStats
    .map((stat, i) => {
      const y = 210 + i * 28;
      const w = relativeFill(stat.value, peak, BAR_W);
      const fill =
        w > 0
          ? `<rect class="bar-fill" x="${BAR_X}" y="${y - 12}" width="${w}" height="14" rx="${Math.min(7, w / 2)}" fill="${c.accent}"/>`
          : "";
      return `
    <text x="${LEFT}" y="${y}" fill="${INK}" font-size="15" font-family="${FONT_ROUND}">${escapeXml(stat.label)}</text>
    <rect x="${BAR_X}" y="${y - 12}" width="${BAR_W}" height="14" rx="7" fill="${c.mid}"/>
    ${fill}
    <text x="${BAR_X + BAR_W + 10}" y="${y}" fill="${INK}" font-size="15" font-weight="600" font-family="${FONT_ROUND}">${escapeXml(formatStatValue(stat.value))}</text>`;
    })
    .join("");
}

/** Giant pastel hanzi, sticker character on top, sparkles, and the pinyin tag. */
function renderHero(zodiac, c, glow) {
  const hanzi = escapeXml(zodiac.hanzi || zodiac.earthlyBranch || "");
  const def = cuteAnimals[zodiac.id];
  return `
    <text x="470" y="236" text-anchor="middle" font-size="230" fill="${c.mid}" font-family="${FONT_HANZI}">${hanzi}</text>
    <g class="character" transform="translate(395 100) scale(1.25)">${def ? renderSticker(def) : ""}</g>
    ${sparkle(538, 34, 22, "#ffd36e", { twinkle: glow })}
    ${sparkle(384, 92, 16, "#ffd36e", { twinkle: glow, begin: "0.8s" })}
    ${sparkle(556, 196, 14, c.accent, { twinkle: glow, begin: "1.6s" })}
    <g transform="translate(392 256)">
      <rect width="156" height="30" rx="15" fill="#ffffff" stroke="${INK}" stroke-width="2.5"/>
      <text x="78" y="21" text-anchor="middle" fill="${INK}" font-size="15" font-family="${FONT_ROUND}"><tspan fill="${c.accent}" font-size="17" font-family="${FONT_HANZI}">${hanzi}</tspan> ${escapeXml(zodiac.pinyin || "")} · “${escapeXml(zodiac.sign.toLowerCase())}”</text>
    </g>`;
}

/**
 * @param {{ profile: object, zodiac: object, stats: object, meta?: { source?: string, width?: number, glow?: boolean } }} input
 */
export function renderCuteCard({ profile, zodiac, stats, meta = {} }) {
  const c = zodiac.cuteColors;
  const uid = `azc-${profile.username}-${zodiac.id}`.replace(/[^a-z0-9-]/gi, "");
  const displayStats = pickDisplayStats(stats, zodiac, 3);
  const login = profile.username || profile.name || "developer";
  const realName = secondaryDisplayName(profile);
  const nameLabel = realName ? `${login} (${realName})` : login;
  const glow = Boolean(meta.glow);

  const displayWidth = clamp(Number(meta.width) || DEFAULT_DISPLAY_WIDTH, 240, 900);
  const displayHeight = Math.round((displayWidth / WIDTH) * HEIGHT);

  const title = zodiac.title.replace(/^The\s+/i, "");
  const titleSize = fitFontSize(title, COLUMN, 28);
  const year = `YEAR OF THE ${zodiac.sign.toUpperCase()}${zodiac.earthlyBranch ? ` · ${zodiac.earthlyBranch}` : ""}`;
  const source = meta.source === "birthdate" ? "by birth year" : "by name-seed";
  const description = descriptionLines(zodiac.description)
    .map(
      (line, i) =>
        `<text x="${LEFT}" y="${106 + i * 17}" fill="${MUTED}" font-size="13" font-family="${FONT_ROUND}">${escapeXml(line)}</text>`,
    )
    .join("\n    ");

  return `<?xml version="1.0" encoding="UTF-8"?>
<svg width="${displayWidth}" height="${displayHeight}" viewBox="0 0 ${WIDTH} ${HEIGHT}" xmlns="http://www.w3.org/2000/svg" role="img" aria-label="${escapeXml(nameLabel)} Asian Zodiac Card">
  <title>${escapeXml(nameLabel)} — ${escapeXml(zodiac.sign)} ${escapeXml(zodiac.title)}</title>
  <defs>
    <pattern id="${uid}-dots" width="22" height="22" patternUnits="userSpaceOnUse">
      <circle cx="4" cy="4" r="2" fill="${c.mid}"/>
    </pattern>
    <clipPath id="${uid}-clip">
      <rect x="3" y="3" width="594" height="314" rx="26"/>
    </clipPath>
    <style>
${CUTE_FONT_CSS}
    </style>
  </defs>

  <rect x="3" y="3" width="594" height="314" rx="26" fill="${c.bg}"/>
  <g clip-path="url(#${uid}-clip)">
    <rect width="${WIDTH}" height="${HEIGHT}" fill="url(#${uid}-dots)" opacity="0.55"/>
    ${renderHero(zodiac, c, glow)}

    <text x="${LEFT}" y="46" fill="${c.accent}" font-size="15" font-weight="600" letter-spacing="1" font-family="${FONT_ROUND}">${escapeXml(year)}</text>
    <text x="${LEFT}" y="82" fill="${INK}" font-size="${titleSize}" font-weight="600" font-family="${FONT_ROUND}">${escapeXml(title)}</text>
    ${description}
    ${renderNameLine(profile)}
    ${renderLanguages(profile.languages, c)}
    ${renderStats(displayStats, c)}

    <text x="${LEFT}" y="300" fill="${MUTED}" font-size="12" font-family="${FONT_ROUND}">Your coding personality written in the Asian zodiac</text>
    <text x="570" y="300" text-anchor="end" fill="${MUTED}" font-size="12" font-family="${FONT_ROUND}">${escapeXml(`${zodiac.element} · ${source}`)}</text>
  </g>
  <rect x="3" y="3" width="594" height="314" rx="26" fill="none" stroke="${c.mid}" stroke-width="3"/>
</svg>`;
}
```
